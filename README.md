# ✈️ Aviation Data Analysis Dashboard

This project analyzes aviation customer satisfaction and flight performance using **Power BI** and **Excel**.<br>
It explores trends in travel types, delays, satisfaction levels, and spending habits at airports.


## 📊 Tools Used

- **Microsoft Power BI** – Interactive dashboards and visual analytics.
- **Microsoft Excel** – Data , PivotTables, charts.



## 📁 Dataset Overview

The dataset includes flight records and customer satisfaction feedback.

| Feature                         | Description                                      |
|---------------------------------|--------------------------------------------------|
| `CustomerID`                   | Unique ID for each customer                      |
| `Satisfaction`                | Customer satisfaction rating (e.g., Satisfied)  |
| `Airline Status`             | Loyalty status (e.g., Blue, Silver)              |
| `Age`                         | Age of customer                                  |
| `Gender`                      | Gender of customer                               |
| `Type of Travel`             | Personal or business                             |
| `Shopping Amount at Airport` | Customer spending at airport stores              |
| `Eating and Drinking Amounts at Airport` | Spending on food and beverages        |
| `Class`                       | Cabin class (Economy, Business, etc.)            |
| `Flight Date`                | Date of the flight                               |
| `No of Flights`             | Total flights taken by the customer              |
| `Flight Cancelled`          | Indicates if the flight was canceled             |
| `Arrival Delay / Departure Delay` | Time delays in minutes                     |
| `Origin / Destination State` | Flight route                                     |
| `Flight Time`               | Time taken during flight                         |
| `Flight Distance`           | Distance covered                                 |
| `Total Delay / Total Flight Time` | Combined delay/total duration               |
